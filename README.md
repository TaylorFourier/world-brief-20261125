## Run it

From the repository root:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the shipped PNG to `$MAKEFUN_OUTPUT_DIR/entry.png`. Node 22 runs the TypeScript as it is. No install and no network.

## Image constraints

The file is a whole PNG named `entry.png`. It is at most 1,048,576 bytes and at most 1024 by 1024 pixels. Two runs write the same bytes.
